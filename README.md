## 提交 Session 信息前，哪些问题要注意？

BeWild.ai 的 ChatGPT 教程要求用户提交一段账号相关的 JSON 或 Session 信息。帮助中心说明，这段信息需要从已经登录 ChatGPT 的浏览器中获取，复制不完整、浏览器未登录或插件改写内容，都可能导致开通失败。

这一步比普通扫码付款更敏感，操作时应注意：

- 只使用自己的 ChatGPT 账号

- 如果复制内容不完整，不要反复提交错误信息
